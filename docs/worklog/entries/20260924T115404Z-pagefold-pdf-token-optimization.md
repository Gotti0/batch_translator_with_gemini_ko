## 배경

Gemini API는 입력된 PDF의 페이지를 이미지 모달리티(~280 토큰/페이지)로 고정 과금하면서 내부 텍스트 스트림을 무료로 추출해 모델 컨텍스트에 주입한다. 커뮤니티에서 발표된 PageFold(0.2.x)는 텍스트를 1~2pt 초소형 폰트의 PDF로 렌더링하여 프롬프트 토큰을 최대 90% 이상 절감하는 기법이다. 본 번역기(BTG)는 수십만 자의 웹소설을 6,000~10,000자 단위 청크로 분할하여 반복 번역하므로, 매 청크마다 주입되는 방대한 용어집·인물설정·세계관 컨텍스트의 누적 토큰 비용이 컸다.

## 문제

PageFold를 번역기에 그대로 적용하기에는 세 가지 기술적 제약과 위험이 있었다.

1. 외부 종속성 문제: 브라우저 환경(jsPDF, Puppeteer 등)과 달리 데스크톱 앱에 무거운 외부 렌더러나 C 바이너리 의존성(PyMuPDF, ReportLab 등)을 추가하면 배포 크기와 플랫폼 호환성이 저하된다.
2. 번역 원문의 문장 누락 위험: 번역할 본문 청크 전체를 PDF로 접어 전달하면, Gemini 모델이 OCR/문서 요약 모드로 전환되어 문장을 임의 축약하거나 누락(omission)하는 치명적 번역 품질 저하가 발생한다. 또한 출력 토큰 상한(8,192 토큰) 때문에 본문 청크를 무작정 키울 수도 없다.
3. 개행 소실 및 인코딩 깨짐: Gemini가 PDF 텍스트 스트림을 파싱할 때 줄바꿈(`\n`)을 공백으로 합치거나 CJK(한글, 한자, 일본어) 및 이모지가 깨지는 문제가 존재한다.

## 결정과 근거

- **순수 파이썬 기반 Zero-Dependency PDF 1.7 엔진 구현 (`utils/pdf_packer.py`)**:
  표준 라이브러리(`zlib`, `struct`)만으로 동적 Adobe `/ToUnicode` CMap 및 FlateDecode 스트림을 생성하는 초경량 PDF 패커를 작성했다. 외부 의존성 없이 한글, 한자, CJK 확장, 결합 분음 기호, 이모지 유니코드 16진수 매핑을 완벽히 지원한다.
- **Reference 모드(용어집 참조 모드)를 1차 표준으로 채택**:
  본문 청크는 일반 텍스트로 보존하여 번역의 원문 충실도와 무결성을 100% 유지하고, 매 청크마다 반복 투입되던 방대한 용어집과 세계관 지침만 1페이지 분량의 1~2pt PDF 바이너리 Part로 패키징했다.
  - **버린 대안: Chunk 모드(본문 전체 PDF화)를 기본값으로 사용.** 토큰 절감률은 극대화되지만 긴 문맥에서 모델이 텍스트를 발췌 번역하거나 문장을 건너뛰는 현상이 확인되어 기본 모드에서 배제하고 실험적 옵션으로만 남겼다.
  - **선택된 절충안: `<pdf>...</pdf>` 태그 모드 병행 지원.** 프롬프트 내에서 사용자가 명시적으로 토큰을 접고 싶은 배경 설명이나 참조 지침만 부분적으로 PDF화할 수 있도록 지원했다.
- **개행 보존 디렉티브 및 복원기 (`restore_response_newlines`) 도입**:
  Gemini가 줄바꿈을 공백으로 병합하는 현상을 방지하기 위해 마커(`[PARAGRAPH_BREAK]`, `[LINE_BREAK]`) 지침을 주입하고, 모델 응답 파싱 시 마크다운 코드 블록(```) 및 이스케이프 문자열을 훼손하지 않고 정규표현식으로 복원하도록 설계했다.
- **클라이언트 및 UI 연동**:
  `GeminiClient.generate_text_async`가 `multimodal_parts`를 수용하도록 확장하고 저해상도 폴백(`MEDIA_RESOLUTION_LOW`)을 적용했으며, PySide6 설정 탭에 토글 스위치, 모드 선택 콤보, 폰트 크기 조절기를 배치했다.

## 검증

- **PDF 엔진 단위 테스트 (`test/test_utils/test_pdf_packer.py`, 8 passed)**:
  유효한 PDF 1.7 헤더·xref·Trailer 구조 검증, 다국어(한글/한자/일본어/이모지) ToUnicode CMap 무결성, 개행 마커 복원 및 코드 블록 보존 로직 통과.
- **도메인 번역 및 클라이언트 연동 테스트 (`test/test_domain/test_pagefold_integration.py`, 3 passed)**:
  Reference 모드에서 용어집 PDF Part 자동 생성 및 캐싱 검증, Marked Tags 모드에서 `<pdf>` 추출 및 텍스트 프롬프트 분리 검증.
- **GUI 설정 연동 테스트 (`test/test_settings_tab_pagefold.py`, 3 passed)**:
  위젯 초기값, 토글 활성/비활성화, `_load_config` 및 `_save_config_to_service` 직렬화 정상 동작 검증.
- **전체 회귀 테스트**: 211 passed, 7 skipped. 기존 인프라 및 번역 파이프라인의 회귀 없음.

## 미해결

- 실제 유료/무료 Gemini 2.0/2.5/3.0 실시간 엔드포인트에서 10만 자 이상의 실전 장편 웹소설을 대상으로 실측 토큰 절감률 및 응답 지연 시간(Latency) 벤치마크를 수행하지 않았다.
- PDF 페이지 수가 10장을 초과하는 초대형 세계관 설정집의 경우 다중 페이지 분할에 따른 토큰 비용(페이지당 ~280 토큰 추가) 증가폭 측정이 필요하다.
